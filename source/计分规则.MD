# 《绿神话》计分规则

> 本规则与《游戏规则.MD》及网页版（存档口径 1.1.0）引擎实现完全对齐，作为单独文件供主持人与教研组直接使用。分数体系分三层：**游戏内企业计分**（原有口径）、**游戏内政府治理量化分**（补齐 PPT 缺口）、**课堂成绩换算**（游戏结果 → 小组平时分）。三层相互独立，可整体采用，也可只取其一。

---

## 一、企业计分（游戏内既有口径）

### 1. 总分与排名

```text
企业总分 = 12 月结束后的最终经济值 + 最终生态值
```

- 三家企业按总分从高到低排名，总分最高者获胜。
- 网页版年终结算页（中控台终局 / 舞台第 42 页）与归档页"年终结算"页签即按此口径自动排序。

### 2. 平级决胜规则（建议开课前宣布）

网页按总分排序，总分并列时按 A/B/C 原序显示；人工裁定按以下优先级逐级决胜：

| 优先级 | 比较项 | 说明 |
| --- | --- | --- |
| 1 | 总分（经济 + 生态） | 主口径 |
| 2 | 最终生态值 | 总分并列时，生态高者名次列前——强化"低碳本身就是竞争力"的课程价值导向 |
| 3 | 低碳资产项数 | 屋顶光伏 / 双向充电桩 / 蓄电池三项的合计拥有数多者列前 |
| 4 | 仍并列 | 并列名次，不继续加赛 |

### 3. 已内嵌于引擎的风险扣分（对账时留意）

- **生态滑坡**：任意时点生态值 ≤ 20，当月边沿触发一次额外 -10（生态），并记入风险日志；
- **濒临破产救助**：经济值首次 ≤ 20 时弹出救助决策，政府可选择发放（企业经济 +10 / 政府财政 -10）或放弃，每家企业全程限一次；放弃不扣分，但政府须在年终复盘说明理由；
- **财政红线**：政府全年任意时点财政不得 < 0，财力不足的政策选项在网页中自动置灰。

上述扣分与救助均已自动计入最终分值，无需人工调整。

## 二、政府治理量化分（补齐 PPT 缺口，100 分制）

PPT 未给政府"获胜分"，仅给出三项治理目标。为使政府组有可量化、可比较的结果，定义治理分 G（0–100）：

```text
G = 生态目标分 + 经济目标分 + 财政目标分 + 财政韧性分
```

| 分项 | 满分 | 计分方式 |
| --- | ---: | --- |
| 生态目标分 | 30 | 30 × min( 全社会总生态 ÷ 240, 1 )，精确到 0.5 分（四舍五入） |
| 经济目标分 | 30 | 30 × min( 全社会总经济 ÷ 320, 1 )，精确到 0.5 分（四舍五入） |
| 财政目标分 | 30 | 最终财政 ≥ 0 得 30 分；< 0 得 0 分（红线一旦击穿，本项清零） |
| 财政韧性分 | 10 | 结余 ≥ 40 得 10；20–39 得 5；0–19 得 2；< 0 得 0 |

设计说明：目标分按达成度比例给分而非全有全无，避免"差 1 分"与"差 50 分"同判；财政韧性分奖励量入为出的预算管理，防止政府为凑目标在年终前孤注一掷。

**取数位置**：三项"全社会总生态 / 总社会经济 / 最终财政"直接读年终结算页的三枚目标胶囊（`✔/✘ 全社会生态 X / 240` 等），无需手工累计。

**可选附加（课堂裁量）**：政策理由陈述质量分 0–10，由教师按政府全年"决策理由"填写质量现场评定。若采用，则将上表四项压缩为 90 分制（各项按 9/10 折算）后叠加，保持总分 100 不变；不采用则忽略本条。

## 三、课堂成绩换算（游戏结果 → 小组平时分）

以下给出一套可直接执行的 100 分制方案（基础分与系数可按课程权重调整）：

### 1. 企业组

```text
企业组课堂分 = 基础分 60 + 名次分 + 绿色转型加分
```

| 名次 | 名次分 |
| --- | ---: |
| 第 1 名 | +30 |
| 第 2 名 | +20 |
| 第 3 名 | +10 |

- **绿色转型加分**：最终拥有屋顶光伏、双向充电桩、蓄电池中的 **≥ 2 项** 加 5 分，< 2 项不加分（与 11 月零碳园区资格口径一致，奖励前瞻性低碳投资）；
- 企业组满分 95，为课堂表现留出余量。

### 2. 政府组

```text
政府组课堂分 = 基础分 60 + 治理分 G × 0.4
```

- G 采用第二节的量化结果（0–100），折算后最高 +40，政府组满分 100。

### 3. 课堂表现加分（全体组通用，教师裁量）

| 表现 | 加分 | 上限 |
| --- | ---: | ---: |
| 政策决策理由陈述（政府组，每次有理有据） | +1～+2 | +5 |
| 获奖感言 / 复盘发言（含教学讨论点 6 问的应答） | +1～+2 | +5 |

单项加分后总分不超过 100。

### 4. 完整示例

某局终局：企业 A 总分 105（生态 45、资产 3 项）、企业 B 总分 122（资产 1 项）、企业 C 总分 90（资产 2 项）；全社会总生态 200、总经济 340、政府财政 35。

- **企业排名**：B（122）> A（105）> C（90）。
- **企业组课堂分**：B = 60+30+0 = **90**；A = 60+20+5 = **85**（资产 3 项 ≥ 2，加 5）；C = 60+10+5 = **75**（资产 2 项，加 5）。
- **政府治理分**：生态 30×min(200/240,1)=25；经济 30×min(340/320,1)=30；财政 35≥0 得 30；韧性 35 落在 20–39 档得 5；G = **90**。
- **政府组课堂分**：60 + 90×0.4 = **96**；若政府组复盘发言再加 3 分且未超上限，记 99。
